API 總覽

此 API 提供給其他服務使用，讓外部系統能夠根據 Discord User ID 獲取用戶的個人頁面 URL。
基本信息
  • Base URL: {{ base_url }}
  • 請求方法: GET
  • 響應格式: JSON
  • 身份驗證: 無需驗證
安全說明
  • 僅返回已驗證用戶的信息
  • 不會洩露敏感用戶數據
  • 支持 CORS 跨域請求

API 端點

GET {{ api_endpoint }}<discord_id>

根據 Discord User ID 獲取用戶的個人頁面 URL

參數說明：
  • discord_id (路徑參數): Discord 用戶的唯一識別碼

請求示例

cURL 示例
curl -X GET "{{ api_endpoint }}123456789012345678" \
  -H "Accept: application/json"
JavaScript (fetch) 示例
const discordId = "123456789012345678";
const apiUrl = "{{ api_endpoint }}" + discordId;

fetch(apiUrl)
  .then(response => response.json())
  .then(data => {
    if (data.success) {
      console.log("用戶個人頁面:", data.profile_url);
      console.log("用戶名稱:", data.username);
      console.log("顯示名稱:", data.display_name);
    } else {
      console.error("錯誤:", data.message);
    }
  })
  .catch(error => console.error("請求失敗:", error));
Python 示例
import requests

discord_id = "123456789012345678"
api_url = "{{ api_endpoint }}" + discord_id

response = requests.get(api_url)
data = response.json()

if data['success']:
    print(f"用戶個人頁面: {data['profile_url']}")
    print(f"用戶名稱: {data['username']}")
    print(f"顯示名稱: {data['display_name']}")
else:
    print(f"錯誤: {data['message']}")

響應格式

成功響應 (HTTP 200)
{
  "success": true,
  "discord_id": "123456789012345678",
  "username": "user123",
  "display_name": "用戶顯示名稱",
  "profile_url": "https://your-domain.com/user/user123",
  "user_id": 42
}
錯誤響應 (HTTP 404)
{
  "success": false,
  "error": "User not found or not verified",
  "message": "找不到該用戶或用戶尚未驗證"
}
錯誤響應 (HTTP 500)
{
  "success": false,
  "error": "Internal server error",
  "message": "伺服器內部錯誤"
}

錯誤代碼說明

HTTP 狀態碼 錯誤類型 說明
200 成功 請求成功，返回用戶信息
404 用戶不存在 找不到指定的 Discord ID 或用戶尚未驗證
500 伺服器錯誤 伺服器內部錯誤，請稍後重試

使用限制與注意事項

重要提醒：此 API 僅供授權的服務使用，請勿用於惡意目的。
  • 請求限制：目前無請求頻率限制，但請合理使用
  • 隱私保護：僅返回公開信息，不包含敏感用戶數據
  • URL 格式：返回的個人頁面 URL 為絕對路徑，包含協議和域名
  • 用戶驗證：僅返回已通過驗證的活躍用戶信息
